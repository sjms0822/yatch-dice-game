# 🎲 요트 다이스 (Yacht Dice) - 3D 물리 시뮬레이션

《세계 게임전집 51》 기반의 공식 룰을 적용한 프리미엄 3D 요트 다이스 게임입니다.  
실제 물리 법칙(Three.js + Cannon-es)을 기반으로 5개의 주사위가 제각기 회전하고 충돌하며 자연스럽게 굴러갑니다.

---

## 🎮 주요 기능

1. **실시간 3D 물리 시뮬레이션 (Natural Physics)**
   - 5개의 주사위가 서로 다른 위치, 초기 속도, 각속도로 던져집니다.
   - 트레이 바닥, 마호가니 원목 벽, 주사위 상호 간의 충돌(Dice-to-Dice Collision)이 정밀하게 계산됩니다.
   - Web Audio API를 활용하여 충돌 강도에 비례하는 청량하고 실감나는 효과음을 재생합니다.
   - 3D 공간의 주사위를 마우스로 직접 클릭하거나 하단 보관함 슬롯을 클릭하여 자유롭게 **보관(KEEP)**할 수 있습니다.

2. **2가지 게임 모드**
   - **👥 2인 로컬 대전 (2-Player Local):** 한 컴퓨터에서 친구, 가족과 함께 번갈아가며 대결합니다.
   - **🤖 AI 1:1 대전 (Vs AI):** 스마트한 전략과 기대값 알고리즘을 갖춘 인공지능과 대결합니다. AI의 고민과 감정이 담긴 실시간 생각 말풍선을 볼 수 있습니다.

3. **요트 다이스 공식 족보 & 스마트 점수판**
   - **상단 영역 (Upper Section):** Aces(1), Deuces(2), Threes(3), Fours(4), Fives(5), Sixes(6)
     - ⭐ **상단 보너스:** 상단 점수의 합계가 **63점 이상**이면 **+35점 보너스** 추가!
   - **하단 영역 (Lower Section):**
     - **초이스 (Choice):** 주사위 5개의 총합
     - **4 오브 어 카인드 (4 of a Kind):** 동일한 눈 4개 이상 시 5개 총합
     - **풀하우스 (Full House):** 3개 동일 + 2개 동일 시 **5개 주사위 눈의 총합**
     - **스몰 스트레이트 (S. Straight):** 연속된 4개 숫자 시 고정 **15점**
     - **라지 스트레이트 (L. Straight):** 연속된 5개 숫자 시 고정 **30점**
     - **요트 (Yacht):** 동일한 눈 5개 시 최고 족보 **50점!**
   - **실시간 프리뷰(Preview):** 주사위를 굴린 후 얻을 수 있는 점수가 점수판에 은은하게 미리 표시되어 최적의 선택을 돕습니다.
   - 축하 폭죽(Confetti) 및 팡파르 연출!

---

## 🚀 실행 방법

### 방법 1 (가장 간편한 방법)
- 폴더 내의 **`게임실행.bat`** 파일을 더블클릭합니다. 기본 웹 브라우저가 열리며 즉시 게임이 시작됩니다.
- 또는 **`yacht_game.html`** 파일을 더블클릭하여 크롬, 엣지, 웨일 등 브라우저로 열어도 즉시 플레이 가능합니다. (서버나 인터넷 연결 필요 없음)

### 방법 2 (개발 서버로 실행)
```bash
npm run dev
# 또는 개발서버실행.bat 더블클릭
```
브라우저에서 `http://localhost:3000`으로 접속합니다.
